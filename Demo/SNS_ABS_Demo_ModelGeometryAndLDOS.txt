//==============================================================================
// SNS_ABS_Demo_ModelGeometryAndLDOS.txt
//
// Purpose:
//   Self-contained model-geometry demonstration of:
//     1. synthetic rectangular SNS geometry,
//     2. central-position ray tracing and trajectory-length distribution,
//     3. 2D and 3D LDOS(E,B) at the center and near an edge,
//     4. top and side projections of representative 3D center trajectories,
//     5. zero-field line DOS across the middle of the geometry,
//     6. a free-vortex 2D surface-state LDOS(x,y,E) calculation.
//
// The calculations retain raw and experimentally broadened outputs. Separate
// normalized copies are created only for display. Re-running the notebook
// deletes and rebuilds root:SNS_ABS_Demo_ModelGeometryAndLDOS.
//==============================================================================
